# Tableau Kanban de bureau

Ouvre `index.html` avec Safari ou Chrome. Tu peux ensuite le placer en plein écran avec le bouton vert de la fenêtre : il fait un joli tableau de fond, tout en restant modifiable.

Tu peux :

- ajouter, renommer, colorer ou supprimer des colonnes ;
- ajouter une tâche avec le bouton « Ajouter une tâche » ;
- cliquer sur une tâche pour la modifier ou la supprimer ;
- glisser une tâche vers une autre colonne, ou changer son ordre dans la même colonne ;
- utiliser le bouton de réglages en haut à droite pour exporter une sauvegarde.

Les changements sont enregistrés automatiquement dans le navigateur utilisé. Pense à exporter une copie de temps en temps.

Note : macOS ne permet pas à une page interactive d’être littéralement derrière toutes les fenêtres comme un fond d’écran. Le mode plein écran est l’alternative la plus simple et sûre ; tu peux revenir au tableau depuis Mission Control quand tu en as besoin.

Pour publier le tableau et le partager, consulte `README.md` : le dossier est prêt pour GitHub Pages.
