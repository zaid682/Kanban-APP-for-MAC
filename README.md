# Mon Kanban — macOS Kanban App
A simple and lightweight Kanban board designed for macOS.
Mon Kanban lets you create colored columns, add tasks, and move them freely around your board. Your data is saved locally on your Mac.
## ✨ Features
- Create and manage Kanban columns
- Add and organize tasks
- Drag and drop tasks
- Move and resize the Kanban window
- Minimize the app to the Dock
- Choose how the Kanban window behaves:
  - **Always on Top** — keeps the Kanban above other applications.
  - **Normal Window** — behaves like a standard macOS application.
  - **Desktop Background** — places the Kanban behind other windows while keeping it above the desktop, so your columns and tasks remain interactive.
- Your columns and tasks are saved locally on your Mac.
## 🚀 Installation
### 1. Install Git
Make sure Git is installed on your Mac.
If you use Homebrew:
```bash
brew install git

You can check your Git installation with:

git --version

2. Clone the repository

Choose the folder where you want to store the application, open Terminal in that location, and run:

git clone https://github.com/zaid682/Kanban-APP-for-MAC.git

3. Open the project folder

cd Kanban-APP-for-MAC

The repository contains the Mon Kanban.app application.

4. Install the application

Move Mon Kanban.app to your Applications folder.

Then double-click the application to launch it.

That’s it. No additional installation is required.

💻 Compatibility

Mon Kanban is currently compiled for Apple Silicon Macs:

* Apple M1
* Apple M2
* Apple M3
* Apple M4
* Later Apple Silicon chips

🔒 Privacy

Mon Kanban does not require an account or an API key.

Your Kanban columns and tasks are stored locally on your Mac.

No external server is required to use the application.

📂 Repository

This repository contains the Mon Kanban application and its source code.

Clone the repository, move Mon Kanban.app to your Applications folder, and start using Mon Kanban.

📌 Note

When opening the application for the first time, macOS may display a security warning because the application is not distributed through the Mac App Store.

If this happens, go to:

System Settings → Privacy & Security

and allow the application to open.
