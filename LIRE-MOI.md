# Mon Kanban — application Mac

Double-clique sur `Mon Kanban.app`. C’est une application macOS autonome : tu peux déplacer sa fenêtre avec la barre tout en haut, la redimensionner et la réduire dans le Dock.

Dans la barre des menus de ton Mac, choisis **Affichage** :

- **Toujours au premier plan** : le Kanban reste visible au-dessus des autres applications.
- **Fenêtre normale** : il se comporte comme une application Mac classique.
- **En arrière-plan du bureau** : il passe derrière les autres fenêtres, mais juste au-dessus du bureau afin de garder les boutons, les colonnes et les tâches utilisables. Tu peux donc les déplacer et les modifier sans couvrir tes autres applications.

Les colonnes et les tâches restent enregistrées localement dans l’application.

## Le partager sur GitHub

Tu peux déposer `Mon-Kanban-Mac.zip` dans les **Releases** de ton dépôt GitHub. Les personnes qui le téléchargent décompressent l’archive puis ouvrent `Mon Kanban.app`. L’application est compilée pour les Mac Apple Silicon (M1, M2, M3, M4 et suivants).
